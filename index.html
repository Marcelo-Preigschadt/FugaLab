Como programar e criar a arma?
Cada linha dá um valor a uma variável: const velocidade = 10; faz o robô correr mais rápido. Altere apenas o número e execute para testar.
Para criar uma habilidade, escreva uma nova linha: const arma = 1;. Segure J ou X para disparar. Arma 0 desliga; 1 é laser; 2 dispara mais rápido; 3 abre três disparos.
Velocidade não tem teto fixo. Pulo: 1 a 30. Barreiras: 0 a 12. Você pode apagar a linha arma para desativá-la. Erros de escrita indicam a linha e mantêm a última versão funcionando.
Editar pausa a simulação. Executar reinicia o trecho nas salas 2 a 6, mantendo inimigos derrotados e checkpoints. R reinicia; P pausa.
